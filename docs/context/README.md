# Ticket context entries

One entry per ticket Biscuit worked on: what changed, where, how it was tested, gotchas and open questions. They are checked into the repo because the app's context library lives in runtime app data. Import them into the library by hand if wanted.

Tickets are those whose commits carry the `Co-Authored-By: Claude Sonnet 5.5` trailer. BWI-40 is this task. Commits without that trailer were not included.

Entries (BWI-11, 12, 17, 19, 22, 23, 25, 26, 27, 32, 33, 34, 37): see `BWI-<n>.md` in this folder.

Details were written from the commit history and diffs. They were not re-run, so check the code before relying on them.
