# Ticket context entries (BWI-42)

One entry per ticket, in `tickets.md`. Each entry has: What changed, Where, Tested, Gotchas, Open questions.

Provenance: built from git history only (commit subjects, bodies, files touched). Git does not record which worker made a commit, and the job records live in the app store, which was not available here. So the entries cover every BWI ticket visible in history. Whoever has the job list should strike out tickets that were not Clover's. Statements not backed by a commit message or file list are marked "unverified".
